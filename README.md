# Бағдар

Персональный маршрут поступления для учеников 10–11 класса Казахстана.
Путь построен как линия метро: **Начало → Анкета → Диагностика → Рекомендации → Сравнение → Маршрут**. На каждом экране видно, где вы находитесь, что пройдено и что дальше.

Правила проекта и контракты — в [CLAUDE.md](CLAUDE.md).

## Запуск

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY нужен только для AI-переформулировок
npm run dev
```

Открыть http://localhost:3000 — корень редиректит на первую станцию `/start`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | дев-сервер |
| `npm run build` | продакшн-сборка |
| `npm run start` | запуск собранного приложения |
| `npm run lint` | ESLint (flat config от `eslint-config-next`) |
| `npm run typecheck` | `tsc --noEmit`, TypeScript strict |
| `npm test` | юнит-тесты движка (Vitest) |
| `npm run e2e` | сквозной проход маршрута (Playwright, viewport 375px) |

Перед первым `npm run e2e`: `npx playwright install chromium`.

## Архитектура

```
src/
  types/index.ts               общие контракты          — правит только лид
  lib/flow.ts                  порядок станций маршрута — правит только лид
  app/layout.tsx               корневой layout          — лид
  app/page.tsx                 redirect на /start       — лид
  app/(flow)/layout.tsx        оболочка пути            — лид
  app/(flow)/start|profile|diagnosis/    экраны         — зона B
  app/(flow)/results|compare|roadmap/    экраны         — зона C
  app/api/                     server routes            — зона C
  components/ui/               дизайн-система           — зона B
  styles/tokens.css            токены                   — зона B
  data/                        программы + доступ       — зона A
  engine/                      движок подбора           — зона A
  store/useJourney.ts          состояние + persist      — зона C
e2e/                           сквозные тесты           — лид
```

Ключевое разделение: **решение принимает движок, не LLM**. `src/engine` — чистые функции без сети и случайности, они возвращают `Recommendation[]` с готовыми `reasons[]`. Языковая модель в `src/app/api` только переформулирует эти причины человеческим языком и не может добавить вуз, требование или дедлайн.

Рекомендации и маршрут не лежат в store — они каждый раз вычисляются из профиля. В localStorage попадают только профиль, выбор пользователя и отметки о выполненных шагах.

## Данные и честность фактов

У каждой программы есть `sourceUrl` и `checkedAt`. Пока факт не подтверждён источником, программа помечена `isDemo: true` и интерфейс показывает бейдж «демо-данные». Неизвестный дедлайн хранится как `null` и выводится как «уточнить на сайте» — выдуманных дат в продукте нет.

Шансы поступления показываются как `high / medium / low` с объяснением. Процентов и гарантий нет: их невозможно посчитать честно.

## Зависимости и зачем они

| Пакет | Обоснование |
| --- | --- |
| `next`, `react`, `react-dom` | App Router из обязательного стека |
| `zustand` | состояние маршрута + `persist` в localStorage; без бэкенда и авторизации этого достаточно |
| `tailwindcss`, `@tailwindcss/postcss` | дизайн-система на токенах, mobile-first вёрстка |
| `typescript`, `@types/*` | strict-типизация контрактов между зонами |
| `eslint`, `eslint-config-next` | линт правил Next и TypeScript |
| `vitest` | юнит-тесты движка: быстрый запуск, нативный ESM и TS |
| `jsdom` | DOM-среда для будущих тестов компонентов зоны B |
| `@playwright/test` | сквозная проверка, что маршрут проходится кликами на 375px |

Отдельно: `@eslint/eslintrc` не нужен — `eslint-config-next` 16 отдаёт flat-config напрямую. Новая зависимость добавляется только с записью в этой таблице.

## Состояние каркаса

Готово: роутинг всех шести станций, прогресс-линия, store с persist и флагом гидрации, контракты типов и движка, демо-фикстуры программ, юнит- и e2e-тесты, зелёные `lint`, `typecheck`, `build`.

Дальше по зонам: A реализует движок вместо `NotImplementedError` и наполняет данные, B собирает анкету и дизайн-систему, C — экраны результата, сравнения, маршрута и server route для AI-переформулировок.
